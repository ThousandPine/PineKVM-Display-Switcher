PineKVM-DisplaySwitcher 使用说明
==========================

作用：
  按 KVM 把键鼠/音箱切到 Mac 时，Windows 自动熄屏，显示器（需开启自动信号源）跳到 Mac；
  键鼠切回 Windows 时自动唤醒。

文件：
  PineKVM-DisplaySwitcher.exe   独立编译的小工具（后台监听，常驻运行）
  PineKVM-DisplaySwitcher.config 配置文件（轮询间隔、确认延时、键鼠 ID）
  src\PineKVM-DisplaySwitcher.cs  C# 源码
  src\编译.bat              一键重新编译（会先停止正在运行的工具）
  启动.bat                立即后台启动（无窗口）
  查看状态.bat            显示当前运行实例的 PID
  设置开机自启.bat        加入 Windows 开机自启（推荐）
  移除开机自启.bat        取消开机自启
  查看日志.bat            用记事本打开运行日志
  PineKVM-DisplaySwitcher.log   运行日志（自动生成）

使用步骤：
  1. 双击“设置开机自启.bat”，以后开机自动运行（推荐）。
     脚本会先移除旧快捷方式再重新注册，可重复点击。
  2. 想立刻运行：双击“启动.bat”（会自动先停止旧实例再启动新实例）。
  3. 按 KVM 切到 Mac：约 1~2 秒后 Windows 熄屏，显示器自动跳到 Mac。
  4. 按 KVM 切回 Windows：键鼠回来后屏幕自动唤醒。
     （要让显示器自动跳回 Windows，另一台电脑也需要同样的“熄屏”联动；
       当前版本只包含 Windows 侧。）

验证是否在工作：
  双击“查看日志.bat”，看到：
    turning monitor off so it auto-switches to Mac  = 触发成功
    Shared devices are back; waking monitor        = 已切回并唤醒

换键鼠后：
  编辑 PineKVM-DisplaySwitcher.config 里的 KeyboardPatterns / MousePatterns，
  保存后重启工具。
  查看当前键鼠 ID 的方法（PowerShell）：
    Get-PnpDevice -Class Keyboard -PresentOnly | Select-Object InstanceId
    Get-PnpDevice -Class Mouse -PresentOnly | Select-Object InstanceId

  其他：
  - 工具以隐藏方式运行，不会出现在前台；任务管理器里进程名为 PineKVM-DisplaySwitcher.exe；
    重复启动会先停止旧实例再启动新实例，无需手动结束进程。
  - 改源码后：双击 src\编译.bat 重新编译，然后双击 启动.bat 运行新版。
  - 查看是否在运行：双击“查看状态.bat”，有 PID 输出即正常。
  - 停止：任务管理器里直接结束 PineKVM-DisplaySwitcher.exe，或先运行“查看状态.bat”
    拿到 PID 后执行 Stop-Process -Id <PID>。
  - 工具只做两件事：键鼠同时消失约 0.5 秒 -> 熄屏；键鼠回来 -> 唤醒。
